# Pickle Shop - Final Deployment Guide

This guide covers the necessary steps to deploy the Pickle Shop from your local machine to production (Vercel) with Supabase as the backend.

## 1. Supabase Initialization
Since we migrated from local SQLite (Prisma) to Supabase, you need to create a `products` table in Supabase.
1. Create a new project in [Supabase](https://supabase.com/).
2. Go to the SQL Editor and run the following command to create your table and insert the default products:

```sql
CREATE TABLE products (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name TEXT NOT NULL,
  price NUMERIC NOT NULL,
  category TEXT NOT NULL,
  unit TEXT DEFAULT 'kg',
  image TEXT NOT NULL,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW()) NOT NULL
);
```

## 2. Pushing to GitHub
Open a terminal in `c:\Users\akhil\Desktop\pickle` and run the following commands to initialize and push your code to GitHub:
```bash
git init
git add .
git commit -m "Final Handover: Ready for Production"
git branch -M main
# Go to GitHub, create an empty repository, and copy the remote link.
# Replace <YOUR_REPO_LINK> below:
git remote add origin <YOUR_REPO_LINK>
git push -u origin main
```

## 3. Vercel Setup
1. Log in to [Vercel](https://vercel.com/) and click **Add New Project**.
2. Import the GitHub repository you just created.
3. Open the **Environment Variables** section before deploying and add the exact Keys defined in `.env.local.example`:
   - `NEXT_PUBLIC_SUPABASE_URL` = (Your Supabase URL)
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` = (Your Supabase Anon Key)
   - `NEXTAUTH_SECRET` = (Any strong random string, e.g. "supersecretpicklekey")
   - `NEXTAUTH_URL` = (Your Vercel deployment URL during second pass, or just omit for Vercel auto-config)
   - `ADMIN_EMAIL` = `admin@pickle.com`
   - `ADMIN_PASSWORD` = `admin123` (Change this!)
4. Click **Deploy**.

Congratulations! Your site is now secure, connected to a live database, and deployed!
